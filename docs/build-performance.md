# Build performance

Generated by `pwsh scripts/measure-build.ps1` from `docs/build-performance.json`. Do not edit it by hand: measure again, or run the script with `-RenderOnly`.

Wall time is the median of the samples, in seconds. Peak memory is the median, in MB, of the most memory each run and everything it started had committed at one moment. Spread is `max - min` across samples. A `kept` label is a setting that stayed because it measured better than the baseline; a `dropped` one was reverted.
