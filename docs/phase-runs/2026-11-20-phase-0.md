## Lessons

- Text written into a file through a PowerShell double-quoted string loses every backtick escape: a shell hook's comment became a command (`e1a5b8d`). Write file text with the Edit tool or a single-quoted here-string, and read the result back.
- A commit message claims only what was read: `3b30421` said a suite passed whose output had not been read (it failed 10 checks).

- A mechanical rewrite across the tree needs every suite that reads a file it changed, not the ones that look related: `D00 T05 §8`'s path scrub turned the `https://github\.com` origin regex in `scripts/lib/overlay.ps1` into `src\.com` (an escaped dot read as a separator after "s:"), which only the overlay clone test reads, and CI caught it (build 44925932774). Run the full gate, or every test of each changed file, before committing one.

- PowerShell variable names ignore case, and three times this run a new variable silently became an existing one: `-Range`'s `[string]$Range` turned the revision list into one string, `$recordOnly` hit the `-RecordOnly` switch, and `$toDay` overwrote `$today`. Each looked like a logic bug before it was found. Before adding a variable to a script, search it for the same name in any case.

- A `git add` that names a path `git rm` already staged fails whole, and twice this run (`fe987e5`, `e0cef60`) the commit after it went out holding only the removal under a message for the whole change. Stage removals and additions in one call only after `git status`, and stop the commit when `git add` exits non-zero.

- A gate that ends must not write over a wait it does not own: the record a guard reads is shared by every gate the session starts, and only the newest is polling.
- A test case for a hang runs in a child process stopped with its tree at a timeout; a thread job cannot be stopped mid-loop, so the regression hung the whole test instead of failing it.
- Text spliced into a file through a PowerShell here-string lost its trailing newline four times this run, the last time joining two steps of `.github/workflows/build.yml` and making the whole workflow invalid (`a5f97b0`, found by `D00 T05 §4` round 1). Multi-line edits go through the Edit tool, and a workflow change is parsed (`yaml.safe_load`) before it is pushed.
