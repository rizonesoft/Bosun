## Lessons
- A heredoc turns `\n` inside a Python string into a real newline as well as halving backslashes: any script or test text holding an escape goes through the Write or Edit tool.
- A test that finds the checkout by walking up to `Bosun.slnx` must also ask for a file only the checkout has: `build/` can hold a copy of the solution.
- Call the CI gate only after `gh run list --commit <sha>` shows the push's own run: called at once, it starts a duplicate run that queues behind the first and doubles the wait.
- Gate the commit that changed code, whose push starts its own run: a record-only commit pushed on top of an ungated code commit has no `build.yml` run of its own (the path filter), so the gate starts one after its grace and it queues behind the code commit's build (21 minutes on `2a9cb72`).
- Two code commits pushed minutes apart queue their builds one behind the other (the workflow's concurrency group), so the second gate waits for both: where a round's fix is small, gate once, on the last code commit.
