## Lessons
- A heredoc turns `\n` inside a Python string into a real newline as well as halving backslashes: any script or test text holding an escape goes through the Write or Edit tool.
- A test that finds the checkout by walking up to `Bosun.slnx` must also ask for a file only the checkout has: `build/` can hold a copy of the solution.
