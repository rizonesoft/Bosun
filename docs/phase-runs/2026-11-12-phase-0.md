## Lessons

- The run guard counts only the repo's own CI gate (`ci_status.py --gate`) as a wait; a hand-written poll of `gh run list` is seen as idle. When the commit to wait on is HEAD, run the gate.
- A throwaway pull request whose commit is made through GitHub's contents API proves a gate's failure without bypassing a local hook.

- A tool whose job is not to miss things draws review rounds until its rules are closed over their own cousins: when a reviewer finds one hole in a rule, look for the next two of the same shape before sending it back.
- Run the whole gate after the last fix, not only the tests of what changed: the wrapper's lone-argument bug passed every targeted test and failed the real step.
- PowerShell splats a single string letter by letter; keep a tail of arguments as an array with `@(...)`.

- A step that is only listed is not proven: the WSL syntax step read well in `-List` and failed the first time it ran. Run each new step once for real.
- Count what a command printed before quoting it in a commit or a stamp; a stamp written with a wrong number was backed out before it was committed.

- A mutation that leaves every test passing can mean the code is redundant, not that a test is missing: the hook's second graph load was found that way.
- A test that makes a fixture executable hides a file shipped without the bit; copy with permissions and assert the mode git recorded.

- A review prompt written through `python -c` on Windows comes out in the console code page, and the dispatcher needs UTF-8: write prompt files with an explicit `encoding='utf-8'`.
- The first push after `D00 T01 §12` waited over twenty minutes on a workflow its path filter had skipped; `D00 T03 §13` makes the gate start that run itself.

- In this shell a heredoc turns a doubled backslash into a single one, so a script written that way loses its backslashes: write PowerShell and Python with backslashes through a file, or avoid the backslash.
- `Move-Item -Force` onto an existing folder moves the file into it and reports success; a replace that must fail on a folder is `[IO.File]::Move($temp, $path, $true)`.
- A .NET constructor given an enum as a string can bind to another overload (`'DeleteOnClose'` became a boolean): pass typed enum values.
- The Stop hook holds the turn while a long local measurement runs in the background, since the guard only knows reviews and CI as waits; waiting in a foreground loop is the way through until the guard learns it.

- A section that imports from another repo is checked against the owner's current scope rule before any comparison work starts: the comparison for `§10` was wasted effort.

- A refusal written inside a function whose output a caller filters (`Get-ProcessList | Where-Object`) is dropped before `exit`, so the run ends silently: write such a refusal to the host.
