## Lessons

- The installed `bosun.exe` can be older than the checkout's: capture a document from `build/Release/bosun.exe`, which is what the tests and CI build.
- A seven-day report is already 1.5 MB: a JSON call's output cap is sized to the largest document its range can make, and tested at that size.
- System.Text.Json's nullable annotations stop a null property but not a null inside a list: a document checks its lists itself.
- A POSIX-semantics rename needs the source opened with DELETE access, which .NET's file APIs can't ask for: a test of it calls `CreateFileW` as the C++ does.
- A tray tooltip holds 127 characters: a reason that begins with a file path loses the reason. Put the short reason first and the whole of it where there is room (the Activity pane).
- A notification refused by Windows is not the person's choice; turned off or paused is: only the first is tried again.
- Gate one commit at a time, the branch's head: `build/ci-gate.json` holds one wait, so a second gate polling beside the first loses its record when the first ends, and the run guard stops holding the run (2026-11-16, D03 T02 §1).
