## Lessons

- Windows refuses the foreground to a process started from a background one, but UI Automation's `SetFocus` on its window gives it: that is how a test brings the panel to the front without sending a key.
- `SendInput` takes `INPUT` at its exact size (40 bytes on x64): a struct padded wrong returns 0 events and sends nothing, silently unless the count is checked.
- A test's own process must be per-monitor DPI aware (a manifest) for UI Automation's rectangles, the pointer and a screen copy to agree on a multi-monitor desktop with mixed scaling.
- A WPF `ContentControl`, `Border` or `StackPanel` has no automation peer, so a name set on one reaches nobody: put it on the control that has a peer (`UserControl`).
- Windows' notification toast lies over the notification area's overflow and a tray menu for some seconds: real input there waits for the point to be uncovered.
- A Git Bash heredoc halves `\b` to ``, which Python then reads as a backspace: a C# regex written through one lost its word boundaries and gained control characters. Code holding backslashes goes through the Write or Edit tool, and a changed file is scanned for control characters.
- A `pre-commit` refusal stops the rest of an `&&` chain: what came after it (here the planned lines and the `Started:` line) never ran, and the next commit swept up the half-done state. Check `git log` after a chained commit.
