## Lessons

- Windows refuses the foreground to a process started from a background one, but UI Automation's `SetFocus` on its window gives it: that is how a test brings the panel to the front without sending a key.
- `SendInput` takes `INPUT` at its exact size (40 bytes on x64): a struct padded wrong returns 0 events and sends nothing, silently unless the count is checked.
- A test's own process must be per-monitor DPI aware (a manifest) for UI Automation's rectangles, the pointer and a screen copy to agree on a multi-monitor desktop with mixed scaling.
- A WPF `ContentControl`, `Border` or `StackPanel` has no automation peer, so a name set on one reaches nobody: put it on the control that has a peer (`UserControl`).
- Windows' notification toast lies over the notification area's overflow and a tray menu for some seconds: real input there waits for the point to be uncovered.
- A Git Bash heredoc halves `\b` to ``, which Python then reads as a backspace: a C# regex written through one lost its word boundaries and gained control characters. Code holding backslashes goes through the Write or Edit tool, and a changed file is scanned for control characters.
- A `pre-commit` refusal stops the rest of an `&&` chain: what came after it (here the planned lines and the `Started:` line) never ran, and the next commit swept up the half-done state. Check `git log` after a chained commit.
- A source that is never shown can't take keyboard focus, so WPF's own focus ring can't be drawn off screen: what needs real focus is proved on the shown window, in the end-to-end smoke.
- A style trigger outranks a template trigger on the control's own property: a template's state colour for a button's words goes on its content presenter (`TextElement.Foreground`), which is also what the words are drawn with.
- Windows ships its contrast themes as `.theme` files under `C:\Windows\Resources\Ease of Access Themes\`: read their colours rather than remember them.
- A process started by hand outside the harness and force-closed leaves its tray icon until the pointer passes over it, and a tray test then finds two: start panels only through `PanelProcess`.
- Windows draws its own caption buttons in a frame extended for Mica while the window has `WS_SYSMENU`; the theme attribute meant for that does not stop it.
- In a contrast theme the accent is the highlight: anything drawn in the accent over a highlight-filled selection (a focus ring, a marker) vanishes. Render the focused and selected states together in contrast.
- A categorical chart's colours must not borrow the state roles: a share drawn in the danger colour reads as an alarm. Choose roles for meaning, not just contrast.
- The installed `bosun.exe` (12 Nov) rejects `status --json`; the panel outside a checkout reads no queue until the operator step `pwsh scripts/install.ps1` runs (todo/99-manual). Noted, not run: every repo's queue uses that binary.
- End-to-end tests that send real keys refuse while a real mouse button is held: a failure then is the person at the machine, not the panel. Rerun when idle before reading it as a defect.
- A timer of a control's own breaks the panel's one-scheduler rule (`RefreshRulesTests`): a timed re-read belongs to the scheduler, started and stopped with what shows it.
- Git Bash heredocs turned a UNC path's backslashes into a tab in a test; such strings go through the Write or Edit tool.
