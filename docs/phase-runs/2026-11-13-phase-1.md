## Lessons
- A heredoc halves backslashes and a Python string then reads what is left: `\taskkill` became a tab. Write any edit with a backslash in it through a script file.
- Ctrl+C can't be sent to another process group, and a process with no console gets no break at all: a cancellation test starts its target in a new process group sharing the console, and sends Ctrl+Break.
- A WSL shim's `bosun.exe acquire` shares the shim's process group, so a dying terminal's hangup killed it with the shim before it could write; `setsid` fixed it (`cb692bf`). A WSL proxy (`/init ... acquire`) from the ended-before-start case was still alive after the run, worth checking when the section resumes.
- `ci_status.py --gate` takes a full SHA and no `--base`; piping it through `tail` hid its argparse exit, so the gate silently never ran and the guard saw nothing in flight. Redirect it to a log and check `run-guard.py status` says waiting.
- A round that stops on a P3 stamps as `stopped-low-severity` with `--cap-outcome`, not `clean`.
- The weakening scan reads answers only as `Weakening scan: <kind> <path>:<id> -- <why>` lines, and a signal's id is its line number at the head, so an edit that moves the line needs its answer again.
- A completion review with `- Filed:` lines stamps as `filed`, even when its in-scope gaps were all fixed.
- A local suite run through `bosun run` can wait many minutes for a slot behind another repo's build; that is the queue working, and the run guard does not count it as a gate.
- A mutation script that rebuilds only for native mutations must rebuild the restored tree before a shell-only mutation, or that one runs against the previous mutation's binary.
- Denying a test folder read or list does not make `fs::exists` fail where bypass-traverse is granted; deny the file itself, and remove the folder's deny before `icacls /reset` on the file.
