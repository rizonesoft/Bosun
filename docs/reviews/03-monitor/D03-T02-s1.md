1. **[P1] WSL jobs can inherit another distro’s slot, command and state.** `src/Bosun.Core/Instances/InstanceClient.cs:177` matches holders using only `guest_pid`, taking the first matching distro. Linux PIDs are not unique across distros. A deterministic regression case can extend the existing fixtures with a Debian job at PID 4321 and put Debian before Ubuntu. 2. **[P2] A small malformed review mark crashes the entire WSL scan.** `wsl/bosun_log.py:249` converts an arbitrary JSON integer using `float(deadline)` without handling `OverflowError`. Reproduce with a `build/review-in-flight/bad.json` file in a running agent’s repo containing `{"pid":1,"deadline":<400 consecutive 9 digits>}`. This 421-byte file passes the size and type checks, then aborts `bosun instances --json` instead of adding a source problem and preserving other instances. Executing the candidate’s unchanged parsing functions with that input confirmed `OverflowError: int too large to convert to float`. Validate the deadline’s range and reject conversion failures.

3. **[P2] A refresh can restart WSL after the user stops it.** `src/Bosun.Core/Instances/InstanceClient.cs:91` launches `wsl.exe -d <distro>` based on an earlier running-distro snapshot. Reproduce by issuing `wsl --shutdown` after `RunningDistrosAsync` returns but before `GuestAsync` launches. The subsequent command starts the stopped distro and VM, violating the no-start polling requirement. The earlier listing does not protect this race; polling needs a reporting path that cannot start a stopped guest.
