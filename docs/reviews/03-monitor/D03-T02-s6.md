## Writer note: the mount reading redesigned at round 4

Rounds 2, 3 and 4 each found one more way a mount can hide a drive (a mount at the same point, then over a parent folder), and each was patched as a case. That is the wrong mechanism, so it is replaced: `drive_mounts` now walks the mount table's parent links from `/` a component at a time, entering at each step what is mounted on top there, as the kernel resolves a path, and counts a mount only when the walk to its mount point reaches it. The stop fallback is widened the same way: whenever this run recorded a lowering and the record is unreadable or absent, the run's own record restores.
