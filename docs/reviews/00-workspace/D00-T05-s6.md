**Strongest alternative: GitHub secret scanning.** It scans history across branches, rescans existing history when it adds secret types, and raises repository security alerts. Bosun’s CI job falls short in two user-visible ways. [GitHub secret scanning](https://docs.github.com/en/code-security/concepts/secret-security/secret-scanning)

Target one reviewed pin update and one full-history rescan for each adopted rules release, including when the repository has had no intervening push.
