### adversarial: needs-attention

1. **P2: Cancellation can leave the current step running until its timeout.** `scripts/check-all.ps1:94` calls `Measure-Job` synchronously. Its implementation blocks inside `WaitForSingleObject` (`scripts/lib/job-measure.ps1:139`), without observing PowerShell cancellation. The cleanup in `finally` cannot run until that call returns. **Reproduction:** run `pwsh scripts/check-all.ps1 -Only python-tests`, then press Ctrl+C while test workers are active. `scripts/run-tests.py` creates workers with `CREATE_NEW_PROCESS_GROUP`, so console Ctrl+C does not stop them; its executor waits for active workers, while the gate remains blocked. Cancellation therefore depends on worker completion or the step timeout, potentially 30 minutes. Add cancellation-aware waiting that terminates the job immediately, and test interruption separately from timeout.

2. **P2: An oversized input file can exhaust memory before any PE validation.** `scripts/native-pe-check.py:121` uses `path.read_bytes()`, allocating memory for the entire file although the check needs only selected headers. Neither file size nor memory consumption is bounded, and `MemoryError` is not handled. **Reproduction:** supply a downloaded or sparse `.exe` larger than available commit memory to `python scripts/native-pe-check.py <path>`. Even a non-PE file causes the full allocation before its signature is rejected, producing severe memory pressure or an uncaught exception. Read bounded header regions through a seekable file and validate offsets against file length.
