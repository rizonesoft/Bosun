When the owner updates the credential in the existing 1Password recovery item, `-FromVault` reads the replacement token but takes its issue day from the item’s original `created_at`. It then writes a matching fingerprint, so preflight accepts the wrong day as belonging to the replacement. An annual renewal can therefore appear expired immediately. Use a day supplied for that token, or treat the day as unknown. The regression should cover replacing the credential in an existing item. `scripts/store-claude-token.ps1:120`, `:130`, `:168`; `tests/start_run_test.ps1:275`.
