## Part 2. Excellence

**Strongest alternative for checkout maintenance: native Git.** A developer can inspect the winning value, its scope, and its source in one command with `git config --show-origin --show-scope --get core.hooksPath`. Git also accepts `-C` to address a checkout independently of the current directory. Bosun adds a combined readiness check and persistent undo, but its failure diagnostics still require more investigation in these cases. [Git configuration reference](https://git-scm.com/docs/git-config) · [Git command reference](https://git-scm.com/docs/git)

1. **Diagnostic round trips — `suggestion`.** `-CheckPrePush` stops at the first failed prerequisite. A developer missing both the scanner script and Gitleaks discovers the second fault only after repairing the first and rerunning. Target one invocation that lists every independently detectable fault, with one remedy per fault and one final exit status. Evidence: `scripts/setup-clone.ps1:70`.
2. **Recovery wording — `suggestion`.** The Windows message names Gitleaks 8.30.1 but its `winget` example omits the version. Bosun’s own scanner already supplies a version-pinned install command, and its Linux message includes the release URL. Target one consistent, copyable install instruction per platform across setup and push. Evidence: `scripts/setup-clone.ps1:93` and `scripts/leak-scan.ps1:86`.
