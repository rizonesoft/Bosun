1. **P1: Concurrent saves can silently discard recorded results or decisions.** `scripts/measure-build.ps1:268` reads the data before an unlocked read-modify-write sequence. Atomic replacement prevents partial files, but cannot prevent lost updates. Reproduce by running two `-DecideOnly` commands concurrently for different existing labels. Both can read the same original JSON, then overwrite each other’s changes while reporting success. Measurement saves have the same race. Protect the complete read, update and save transaction with a shared lock.

2. **P2: Cached compiler variables restore another shell’s library paths.** `scripts/lib/dev-env.ps1:55` stores complete changed values, and line 43 restores them wholesale. Visual Studio’s installed `vcvars.bat` prepends its paths to the inherited `LIB` and `LIBPATH`, so these cached values include caller-specific paths. Reproduce by populating the cache from a plain shell with a custom `LIB`, then building from another plain shell with a different `LIB`. The second build silently receives the first shell’s library search path, potentially failing or resolving unintended libraries. Preserve inherited portions when replaying, or invalidate the cache when those inputs differ.
