## Part 2. Excellence

The strongest alternative for credential delivery is **1Password CLI `op run` with a secret reference**. It resolves the reference when launching the requested process and supplies the token for that process’s lifetime. Bosun’s one-time import has a different operational benefit: later launches can use the stored token without contacting the vault. [1Password CLI documentation](https://developer.1password.com/docs/cli/secrets-environment-variables/)

1. **suggestion**. Bosun leaves a reusable credential in the Windows user environment until removal. For an owner who prefers process-scoped access, the target is one campaign launch with zero persistent token writes and no token inherited by subsequently opened, unrelated shells.
2. **suggestion**. Changing the vault value takes effect on the next `op run` launch. Bosun’s existing stored copy requires another import. For a process-scoped launch, the target is to use the updated value on the next start with zero manual reimports.
