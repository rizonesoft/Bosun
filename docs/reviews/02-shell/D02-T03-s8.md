Comparison: **Visual Studio Code’s Command Palette**, as a strong benchmark for keyboard command discovery, rather than a replacement for Bosun’s machine-management functions. [Command Palette documentation](https://code.visualstudio.com/docs/editing/getting-started/userinterface), [similar-command search](https://code.visualstudio.com/updates/v1_83#_similar-command-results-in-the-command-palette).

1. **suggestion**: Search requires a contiguous substring. `sv set` cannot find “Save settings”; the user must repair the query despite having identified the command. Target: support ordered word-prefix or fuzzy matching while retaining the decided prefix/word-start/substring priority. Measure representative queries against VS Code, with a target below 50 ms at Bosun’s actual command count. Evidence: `CommandIndex.cs:28`.

2. **suggestion**: Repeating a command requires searching again because opening clears the query and returns to page-first order. VS Code offers recently used commands. Target: an eligible last-used action reachable with two gestures, open then Enter, without bypassing confirmation. Bosun currently needs at least three, open, query, Enter. Evidence: `CommandPalette.cs:117`, `:197`; [Microsoft’s recent-command discussion](https://github.com/microsoft/vscode/issues/277311).
